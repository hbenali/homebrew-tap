# hbenali/homebrew-tap

Homebrew formulae for [hbenali](https://github.com/hbenali)'s projects.

```sh
brew install hbenali/tap/logscrub
```

[logscrub](https://github.com/hbenali/logscrub) masks secrets and personal data in logs so they can be shared safely.
The formula points at the release archives on GitHub and carries the SHA-256 from each release's own `checksums.txt`;
it is generated by `scripts/update-tap.sh` in the logscrub repository.
